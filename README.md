# Сайт «Рибне місце»

Готовий сайт закладу з онлайн-меню, бронюванням столів, замовленням з собою та адмін-панеллю для власника.

## Що вміє

**Для гостей** (головна сторінка `/`):

- меню з фото, цінами, вагою і фільтром за категоріями;
- бронювання столу: дата, час, кількість гостей і вибір вільного столу;
- замовлення з собою на конкретний час (оплата при отриманні);
- галерея фото, контакти, години роботи, посилання на TikTok, Instagram і Google Maps;
- встановлення на телефон як застосунок (PWA).

**Для власника** (адмінка `/admin`, вхід за паролем):

- **Сьогодні.** Усі броні та замовлення за день зі статусами («Підтверджено», «Готується», «Готове» тощо). Список оновлюється сам кожні 30 секунд.
- **Меню.** Додавання, редагування й видалення страв, ціни, опис, вага, фото та позначка «немає в наявності». Також керування категоріями.
- **Фото.** Головне фото сайту і галерея «Атмосфера».
- **Столи.** Назви, кількість місць, увімкнення та вимкнення столів.
- **Статистика.** Броні, замовлення й виручка за 30 днів, популярні страви, база гостей із телефонами.
- **Налаштування.** Назва, адреса, телефон, години роботи, соцмережі, вимикачі бронювання й замовлень, Telegram-сповіщення, зміна пароля.

Кожна нова броня і замовлення одразу приходить у Telegram.

Зміни в адмінці з'являються на сайті відразу, програміст для цього не потрібен.

## Запуск на своєму комп'ютері (перевірити)

Потрібен Node.js 18 або новіший.

```bash
npm install
cp .env.example .env      # впишіть ADMIN_PASSWORD
npm start
```

Сайт відкриється на http://localhost:3000, адмінка на http://localhost:3000/admin.

## Розміщення в інтернеті (безкоштовно)

Сайт працює на **Render Free**, а всі дані (меню, броні, налаштування, фото) зберігаються в безкоштовній базі **Turso**.

1. **Turso:** зареєструйтесь на turso.tech через GitHub. Створіть базу (Create Database, регіон Frankfurt / AWS eu-central-1).
   Скопіюйте **Database URL** (`libsql://...turso.io`) і створіть токен (**Create Token**).
2. **Render:** Web Service з цього репозиторію, Build `npm install`, Start `npm start`, тарифний план **Free**.
   У розділі Environment додайте:
   - `TURSO_DATABASE_URL`: адреса бази;
   - `TURSO_AUTH_TOKEN`: токен;
   - `ADMIN_PASSWORD`: пароль до адмінки.
3. **Щоб сайт не засинав:** безкоштовний сервер Render засинає після 15 хвилин без відвідувачів.
   На uptimerobot.com створіть монітор HTTP(s) на адресу `https://ВАШ-САЙТ.onrender.com/healthz` з інтервалом 5 хвилин.

Якщо раніше сайт працював на платному плані з диском, при першому запуску з Turso всі дані й фото з диска переносяться автоматично.
Після цього диск можна видалити, а план змінити на Free.

## Telegram-сповіщення

1. У Telegram напишіть @BotFather, команда `/newbot`, і скопіюйте токен.
2. Напишіть своєму новому боту `/start`.
3. Свій chat ID дізнайтесь через @userinfobot. Якщо сповіщення мають приходити в групу персоналу, додайте бота в групу і візьміть ID групи.
4. В адмінці відкрийте **Налаштування**, вставте токен і chat ID, натисніть «Зберегти», а потім «Надіслати тест у Telegram».

## Резервні копії

Усі дані лежать у базі Turso. Повну копію можна зробити командою `turso db shell НАЗВА-БАЗИ .dump > backup.sql` (потрібна програма Turso CLI) або попросити розробника.

## Чого поки немає

- **Онлайн-оплата.** Щоб її підключити, закладу потрібен договір еквайрингу, наприклад Monobank, LiqPay або WayForPay. Ключі від нього потім додаються в код.
- **SMS-нагадування гостям.** Для них потрібен SMS-сервіс, наприклад TurboSMS, що коштує близько 1 грн за SMS.
- **Окремі акаунти для кожного працівника.** Зараз в адмінку входять одним спільним паролем.
